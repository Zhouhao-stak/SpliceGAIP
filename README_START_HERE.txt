========================================
  SpliceGAIP - Quick Start Guide
========================================

SIMPLE 3 STEPS:

========================================
Step 1: Start Docker Desktop
========================================

1. Press Windows key
2. Type: Docker
3. Click "Docker Desktop"
4. Wait for the whale icon to appear (bottom-right corner)

DONE when you see: Docker Desktop is running


========================================
Step 2: Run the launcher
========================================

1. Open folder: E:\SpliceGAIP
2. Double-click: docker-run.bat
3. Type: 1
4. Press Enter
5. Wait a few minutes (first time only)

DONE when you see: SUCCESS!


========================================
Step 3: Open your browser
========================================

1. Open Chrome/Edge/Firefox
2. Type in address bar: localhost:8501
3. Press Enter

DONE! You will see the SpliceGAIP interface!


========================================
Next Time (Quick Start)
========================================

1. Make sure Docker Desktop is running (whale icon)
2. Double-click: docker-run.bat
3. Type: 2 (Start existing container)
4. Open browser: localhost:8501


========================================
To Stop
========================================

1. Double-click: docker-run.bat
2. Type: 3 (Stop service)


========================================
Troubleshooting
========================================

Q: Says "Docker not installed"?
A: Install Docker Desktop from:
   https://www.docker.com/products/docker-desktop

Q: Says "Docker service not running"?
A: Start Docker Desktop first (Step 1)

Q: Takes long time downloading?
A: Normal for first time, please wait

Q: Browser shows error?
A: Make sure Step 2 completed successfully first
